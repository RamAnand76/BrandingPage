# Workspace Rules

- **Mobile First & Compatibility:** Always ensure all layout, component, and design changes are fully mobile-responsive and visually flawless across all mobile device screen sizes (no horizontal overflow, appropriate padding/margins, clear text hierarchy, and hidden/repositioned desktop-only elements).
- **Layout Spacing & Grid Padding:** Maintain uniform section containers. Standard section width is `max-w-[1240px]` (except footer/navbar at `max-w-[1380px]`) with horizontal padding of `px-6 md:px-12 lg:px-16` on all pages to ensure flawless layout alignment. Set vertical spacing between consecutive sections to moderate margins (`py-12 lg:py-16` or `mb-16 lg:mb-20`).
